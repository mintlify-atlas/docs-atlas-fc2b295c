## Transaction Submission

BlockRazor offers four distinct transaction submission modes, each engineered for a different client profile:

- **RPC** — Standard JSON-RPC methods with integrated MEV protection and support for real-time rebates.
- **Gas Sponsor** — Gas fee sponsorship for users who lack sufficient native tokens, dramatically improving onboarding and trading experience.
- **Fast** — A global acceleration network that boosts on-chain transaction speeds, ideal for users with extreme latency requirements.
- **Bundle** — Execute transactions within the same block as a "signal transaction" via Bundles, built specifically for backrunning, copy trading, and token sniping.

## Streams

BlockRazor's streaming layer delivers real-time on-chain data with minimal latency across multiple feed types:

- **Mempool** — Low-latency pushes of pending transactions, enabling users to monitor signal transactions for backrunning, copy trading, and sniping in real time.
- **Block Stream** — Low-latency block data so trading programs can monitor confirmed signal transactions or other transactions as they land.
- **Network Fee Stream** — Real-time pushes of Gas Price, Priority Fee, or Tips based on recent historical block data.
- **Node Stream** — Synchronize data with full nodes for low latency and keep the world state updated in real time.

## Block Builder

BlockRazor's [Block Builder](/block-builder/overview) provides BSC block building services based on the PBS (Proposer-Builder Separation) architecture. Deployed across multiple regions worldwide with low-latency communication to validators, Block Builder runs multiple algorithms to maximize block value and construct competitive blocks. BlockRazor's Block Builder has achieved a historical cumulative block production rate of **37%**, ranking first across the entire BSC chain.
